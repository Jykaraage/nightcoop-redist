# Third-party software

This repository distributes setup scripts and documentation, not the game or mod binaries.
The repository's MIT license covers this kit's original files only.

| Component | Source | Handling |
| --- | --- | --- |
| Cyberpunk 2077 | [CD PROJEKT RED](https://www.cyberpunk.net/) | Each player supplies their own installed copy; no game files are distributed. |
| NightCoop | [Official downloads](https://nightcoop.net/download.html) | Each player downloads the pinned archive directly. No license for redistribution of NightCoop.dll was identified in that archive; this kit does not redistribute it. |
| RED4ext | Included in the official NightCoop archive | The archive includes `red4ext/LICENSE.txt` (MIT) and `red4ext/THIRD_PARTY_LICENSES.txt`; installed unchanged. |
| NightCoopFlight scripts | Included in the official NightCoop archive | The archive includes `r6/scripts/NightCoopFlight/LICENSE.txt` (MIT) and `THIRD_PARTY.md`; installed unchanged. |

All third-party components retain their own licenses and notices. This kit is not an official NightCoop or CD PROJEKT RED release.
